📊 Data Visualization Overview
Data visualization is the graphical representation of information and data. By using visual elements like charts, graphs, and maps, data visualization tools make it easier to understand trends, outliers, and patterns in data.

In this project, data visualization is used to display student CGPA scores across different semesters. It transforms raw data from a JSON file into an intuitive bar chart, enabling users to:

Compare academic performance between students

Identify high and low performers

Observe CGPA distribution per semester

🎯 Purpose of Visualization in This Code
✅ Simplify Complex Data: Instead of reading numbers, viewers can quickly grasp performance trends.

✅ Make Comparisons Easy: Each student’s performance is visually compared using bar heights.

✅ Highlight Key Information: CGPA labels on each bar add clarity and precision.

✅ Interactive Exploration: Users can select semesters dynamically and explore data via sidebar controls.

🔍 Why Bar Charts?
Bar charts are ideal for this type of categorical data (student IDs) and numerical values (CGPA). They:

Emphasize differences in individual student scores

Work well for discrete comparisons

Allow easy readability, especially when color and size are optimized

🌈 Enhanced Visual Appeal
The chart uses a color gradient from the Plasma colormap to make the bars visually appealing and distinguishable. This adds a layer of depth and makes the chart more engaging for the user.
